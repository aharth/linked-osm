Example URIs

Every feature, query and tile below has a dereferenceable URI — browsers get GeoJSON by default, add .ttl/.rdf or an Accept header for RDF.

OSM API

Straight from api.openstreetmap.org, no proxying.

  • /osm/node/1 · Turtle — node by ID, straight from the OSM API
  • /osm/way/32113829 — way by ID, Palas building
  • /osm/relation/51477 — relation by ID, Germany
  • /geo/osm/way/32113829 — geometry-only GeoJSON (no RDF), straight from the OSM API
  • /changeset/1 — RDF only, no JSON; OpenStreetMap's first-ever changeset (Steve Coast, 2005-04-09)
  • /tag/amenity.json · RDF — SKOS representation of an OSM tag key, sourced from taginfo

Nominatim

Geocoding, not feature lookup.

  • /nominatim/search?q=Kaiserburg — place-name search via Nominatim

Overpass

Bbox and bulk queries the OSM API itself can't do.

  • /overpass/relation/147 — same shape as /osm/relation/*, served via Overpass instead of the OSM API directly (Tigris River)
  • /geo/overpass/relation/147 — geometry-only GeoJSON via Overpass
  • /overpass/features?bbox=…&type=nwr — all features in a bounding box, Kaiserburg, Nuremberg
  • /overpass/poi?bbox=…&filter=amenity=cafe — points of interest in a bounding box
  • /overpass/around?lon=&lat=&radius= — nodes within a radius of a point, Kaiserburg

Commercial APIs

Vector tile passthrough to Protomaps' hosted basemap API (/tile/protomaps/{z}/{x}/{y}.mvt) — trusted requests only (bearer key or whitelisted network), 403 otherwise; see FAQ. Same point (Kaiserburg, Nuremberg) at three zoom levels, up to Protomaps' maxzoom of 15:

  • /tile/protomaps/5/16/10.mvt — z5, continent scale
  • /tile/protomaps/10/543/349.mvt — z10, regional scale
  • /tile/protomaps/15/17392/11189.mvt — z15, Protomaps' maxzoom

Passthrough to Tracestrack's raster, vector, terrain-RGB and elevation APIs — same trust gate as Protomaps above, using the wrapper's own paid key so callers don't need one of their own. Same point (Kaiserburg, Nuremberg), z10:

  • /tile/tracestrack/en/10/543/349.webp — raster, English labels, standard style
  • /tile/tracestrack/topo_en/10/543/349.webp?style=dark2 — raster, topographic base, dark colour variant
  • /tile/tracestrack/vt/carto/10/543/349.pbf — vector tile, carto dataset
  • /tile/tracestrack/terrain-rgb/10/543/349.webp — terrain-RGB elevation tile

POST /tracestrack/elevation with a JSON array of {"lat":…,"lon":…} returns a ground elevation per coordinate — not a clickable URI, see Tracestrack's own docs for the request shape (forwarded through unmodified).

Wrapper

Introspection into the wrapper itself, not an upstream.

  • /sparql.html — interactive SPARQL query form over the wrapper's own data; machine clients POST/GET /sparql?query=… with a .json/.xml/.tsv/.ttl/.rdf suffix or Accept header
  • /routes.json — machine-readable manifest of every deployed route, its formats and query params — introspected from the live deployment, not hand-maintained
