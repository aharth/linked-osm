OpenStreetMap Linked Data Wrapper

Welcome to the EXPERIMENTAL OpenStreetMap wrapper to Linked Data. OpenStreetMap data is licensed under the Open Database License (ODbL).

We maintain a document with Frequently Asked Questions and a bot page.

Search by place name

Search for countries, cities, or other places via Nominatim (usage policy).

Example countries

search?q=Germany (map)
Germany — Nominatim API
search?q=France (map)
France
search?q=United+Kingdom (map)
United Kingdom
search?q=Netherlands (map)
Netherlands
search?q=Kaiserburg (map)
Kaiserburg, Nuremberg

Map data by bounding box

Get nodes, relations and ways inside a bounding box via OSM API 0.6.

map?bbox=11.075,49.457,11.077,49.459 (map)
Kaiserburg Nuremberg
map?bbox=2.348,48.856,2.350,48.858 (map)
Louvre, Paris

Points of Interest

Get points of interest (amenity nodes) inside a bounding box via Overpass API.

poi?bbox=11.075,49.457,11.077,49.459 (map)
Points of interest near Kaiserburg Nuremberg
poi?bbox=2.348,48.856,2.350,48.858 (map)
Points of interest near the Louvre, Paris

Around a point

Get nodes within a radius around a point via Overpass API.

around?lon=11.077&lat=49.458&radius=100 (map)
Nodes within 100m of Kaiserburg Nuremberg
around?lon=2.349&lat=48.857&radius=100 (map)
Nodes within 100m of the Louvre, Paris
around?lon=-0.127&lat=51.501&radius=100 (map)
Nodes within 100m of Westminster, London
