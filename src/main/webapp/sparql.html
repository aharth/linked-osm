SPARQL

Execute SPARQL queries over OSM Linked Data loaded via FROM and FROM NAMED clauses. Graph URIs must resolve to this wrapper's own endpoints (e.g. FROM </map.rdf?bbox=…>); external graph URIs are rejected. Result format by URL suffix (/sparql.json, .xml, .tsv; .ttl/.rdf for CONSTRUCT/DESCRIBE) or Accept header.
