osmwrap bot

The osmwrap bot is an automated HTTP client that fetches data from upstream OpenStreetMap services on behalf of the linked-osm wrapper.

Upstream sources

OSM API 0.6
nodes, ways, relations, and changesets
Nominatim
geocoding and place search
Overpass API
points of interest, around queries, and geometry

User-Agent string

All upstream requests carry:

linked-osm/1.0.0-SNAPSHOT (+https://github.com/aharth/linked-osm)

Contact

If you are an upstream service operator and have questions or concerns about these requests, please contact: bot@ontologycentral.com.
