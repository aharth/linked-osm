osmwrap bot

The osmwrap bot is an automated HTTP client that fetches data from upstream OpenStreetMap services on behalf of the linked-osm wrapper.

It is used to proxy requests to:

  • OSM API 0.6 — nodes, ways, relations, changesets, and map data
  • Nominatim — geocoding and place search
  • Overpass API — points of interest, around queries, and geometry

User-Agent string

All requests from this service carry:

linked-osm/1.0.0-SNAPSHOT (+https://github.com/aharth/linked-osm)
